# Changelog

All notable changes to Reignition Tooling are documented here.

## [0.1.0] - 2026-08-15

### Added

- **gas-editor** - visual editor for Dungeon Siege UI (GAS) interfaces: canvas
  view with snap-to-grid, multi-select, copy/duplicate, and a live
  demo-preview mode; also edits generic (non-interface) GAS documents as a
  block tree.
- **skrit-editor** - editor for Skrit scripts: compiles in the editor with
  warnings/errors surfaced inline, disassembles bytecode, and supports
  outline-based navigation.
- **tank-editor** - browser/editor for tank archives (`.dsres`/`.ds2res`/
  `.ssres`): drag-and-drop file add, search/filter across entries, staged
  edits with rebuild.
