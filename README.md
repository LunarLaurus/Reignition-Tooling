# Reignition Tooling

A modern, advanced, Rust-based content toolkit for Dungeon Siege, Dungeon
Siege II, and Space Siege - `gas-editor`, `skrit-editor`, and `tank-editor`.

This repository ships **binary releases only**. Each editor is a single
self-contained executable (no DLLs or data files required); open a file by
passing it as an argument or dragging it onto the window.

| Editor | Opens |
|---|---|
| `gas-editor` | `.gas` UI interfaces and generic fuel documents |
| `skrit-editor` | `.skrit` scripts (compile, disassemble, diagnostics) |
| `tank-editor` | `.dsres`/`.ds2res`/`.ssres` tank archives (browse/edit/rebuild) |

See the [Releases](../../releases) page for downloads.
